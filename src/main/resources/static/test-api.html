Evidencias del Laboratorio

Probador Visual de API REST con JWT

Permite evidenciar la autenticación Stateless de apiFilterChain (@Order 1) sin necesidad de Postman.

1. Autenticación: POST /api/auth/login

Envía credenciales en JSON para validar con AuthenticationManager y recibir el token JWT.

2. Consulta Protegida: GET /api/tareas

Envía el header Authorization: Bearer <token> validado por JwtAuthFilter.
